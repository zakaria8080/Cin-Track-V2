# Cin-Track-V2
Application web de gestion et d'interaction avec un catalogue de films et de séries, développée en JavaScript moderne (ES6+), HTML5 et Tailwind CSS avec une API REST sur MockAPI.

## Fonctionnalités principales
- **Administration (CRUD)** : consulter, ajouter, modifier et supprimer des films et séries (avec confirmation et validation des formulaires).
- **Commentaires** : lire et publier des commentaires depuis la fenêtre modale (modal) de détails d'un contenu.
- **Notation (Bonus)** : attribuer une note de 1 à 5 étoiles et afficher la note moyenne (`reduce()`).
- **Bonus techniques** : `Promise.all()`, opérateur spread (`...`), debouncing de recherche et prévisualisation d'image.

## Stack technique
- HTML5, Tailwind CSS, JavaScript ES6+ (ES Modules : `import` / `export`)
- Fetch API (`async` / `await`, `try` / `catch`, `response.ok`) avec `GET`, `POST`, `PUT`, `DELETE`
- MockAPI.io (endpoint personnel par apprenant)
